运行说明

插件不接管 CPA 的调度职责。

  • 凭据池化、故障转移与会话亲和由 CPA 负责；插件不实现密钥选择、冷却或健康检查调度。
  • 如需会话亲和，请在 CPA 配置中启用 routing.session-affinity: true。
  • 导入的密钥保存在 CPA 的 auth-dir 中；页面仅显示凭据元数据，不回显上游密钥。

管理会话

管理密钥只在验证成功后保存，且不会与其它插件共享。

勾选“记住登录”时，CPA 管理密钥仅保存在本插件按插件 ID 与反向代理前缀隔离的命名空间；不勾选则仅保存在当前标签页会话，存储不可用时退回内存。

启动时仅验证一次。确认失效（401）后清除本插件凭据并返回登录；权限拒绝（403）说明远程管理或网络限制，不当作密钥无效；网络或 5xx 保留凭据并允许手动重试，不自动重复认证。

仅 CPA 管理密钥可被记住。上游 API key 与客户端 API key 不会进入浏览器存储，也不读取 Observer 或宿主的凭据。
