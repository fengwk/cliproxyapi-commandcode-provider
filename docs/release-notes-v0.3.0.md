# CommandCode Provider v0.3.0

管理界面与 Observer 对齐；本插件仍是独立的 CommandCode Provider 页面，不包含其它插件的切换或依赖。

## 界面与交互

- 管理认证独立为登录页，登录后分为“密钥管理 / 手动模型 / 设置”三页。
- 密钥列表增加本地搜索、状态/模式筛选与概览；导入和所选凭据配额使用弹窗，不自动轮询或汇总不同凭据的额度。
- 保留 CLI/Provider 导入模式、行级模式显式保存与 PATCH 后 GET 确认；失败或未确认时保留选择，不把异常模式伪装成 CLI。
- 保留四类点数、真实速率/月度窗口、UTC 重置及来源说明；运行状态只读展示，旧凭据使用实际默认模式。
- 保留手动模型校验→保存→有界双回读确认和失败草稿，离开/退出时提供未保存确认。
- 统一暖灰/纯白/深色/跟随系统与中性控件。嵌入继承宿主主题、隐藏重复品牌/主题控制、保留页签；内容、窄屏页签和弹窗按钮避让 CPA 原生右上悬浮条。

## 管理登录与安全

- 仅验证成功的 CPA 管理密钥可按“记住登录（仅限可信设备）”保存在本插件、当前反向代理前缀隔离的浏览器存储。未勾选使用当前标签页会话，存储不可用时降级并提示。
- 启动仅校验一次已存登录。401 清除本插件凭据与页面数据；403、网络或服务端错误保留已存凭据并允许手动重试，不自动重复认证。退出清除本插件两处存储和内存状态。
- 不读取宿主、Observer 或其它插件凭据。上游与客户端 API key 不进入浏览器存储、URL 或日志，HTTPS/回环安全门与生产 CSP 保持不变。

## 升级与验证入口

保留现有插件设置与上游凭据，升级对应平台原生库、重启 CPA 后刷新插件页即可。不迁移数据、不要求重新导入；本版不修改 CPA、Observer、上游协议/额度算法或 SDK 依赖。

发布验收使用合成凭据和回环 mock：`make test`、`make race`、`make static`、原生构建与实际 CPA v8.0.23 隔离集成；浏览器入口为 `internal/web/browser/session-layout.py`，覆盖登录恢复、导入、模式保存确认、配额、退出和三主题×1440/768/390px 悬浮区避让。另对固定 SHA 的官方 CPA 管理壳验证嵌入、滚动和弹窗布局。
