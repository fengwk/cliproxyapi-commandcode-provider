# CommandCode Provider v0.2.1

本次只优化插件管理界面，不修改 CPA 核心、传输协议、凭据模式或调度逻辑，不增加运行时依赖。

## 界面优化

- 原生选择框继续作为值、选项和 change 事件的单一来源，新增 CPA 风格浮层菜单，支持方向键、Home/End、Enter/Space、Escape、Tab 与标签聚焦。
- 模式导入、每凭据模式及手动模型协议使用统一下拉；打开或高亮选项不会发起写入或上游探测。
- 常规控件收紧到 34px、凭据行控件到 28px；粗指针设备保留 44px 触控目标。
- 对齐 CPA 的浅色、纯白和深色主题、卡片间距与菜单圆角；移动端表格在容器内滚动，不产生整页横向溢出。
- 长 iframe 菜单按宿主可见视口定位，点击宿主外部区域可关闭；重复刷新凭据列表不会残留旧菜单或触发器。

## 保持不变

- 保存每凭据模式仍执行 PATCH 后 GET 回读确认；写入失败或无法确认生效时保留选择草稿，不误报成功。
- 密钥只用于当前输入及 Authorization 请求头，不写浏览器存储或 URL。
- 安装源、插件 ID、配置与凭据格式不变。可直接从插件商店升级至 v0.2.1，无须重新导入凭据。

## 验证

- Go test/vet/race、原生构建、55 项 Node UI 测试及 CPA v8.0.23 本地假上游集成测试通过。
- 13 项真实 Chromium 检查覆盖三主题 × 1280/768/390px、键盘操作、重复重载、模式回读与失败草稿、触控目标、CSP 和密钥保护。
- 发布流程对准确 tag 重新验证，并构建 linux/amd64、linux/arm64、macOS/arm64 安装包与 checksums.txt。
- 全部运行时验证只使用合成凭据与 loopback 服务；不代表对真实服务套餐或扣费行为的验收。
