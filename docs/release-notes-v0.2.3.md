# CommandCode Provider v0.2.3

增加月度额度进度条和真实账期重置日期，保留既有五小时、每周窗口及信用余额。
不修改 CPA 核心、凭据模式、配置格式或调度逻辑，不增加依赖。

## 月度额度

- 配额 API 增加可选 `monthly` bucket，自带中文界面显示“月度额度”，CPA 原生配额卡片也可显示月度进度。
- 总额优先按可用本期授额 `monthlyCreditsGranted` 与官方套餐基准确定；没有授额时仅对已知套餐使用带日期、来源明确的官方基准快照。
- 剩余月余额不再被误当作总额：剩余比例为 `monthlyCredits / total`；团队按官方规则处理席位，不把充值或免费余额混入月 cap。
- 来源说明明确区分 API 本期授额与官网套餐基准。未知套餐且无可信授额、余额缺失、非法授额、欠费状态或总额溢出时，不伪造月度进度。
- 重置时间来自订阅账期结束时间，不猜测固定自然月；非法或不可表示的日期不影响其他有效窗口。
- 保持按所选凭据进行两个只读请求、短超时、无自动轮询、无上游额度重置、无密钥浏览器持久化。

## 升级与验证

- 保留现有配置与凭据，无须重新导入。升级后点击“刷新额度”。
- Go 单测/vet/race、Node UI、原生构建、CPA v8.0.23 隔离集成与 Chromium 回归均使用合成凭据、本地 mock。
- 官网 Web 与插件 CLI 接口路径不同，未使用真实 key 验证账号响应。官网基准为 2026-10-14 的公开快照，不冒充实时账号上限。
- CommandCode 缓存读占比及非零成本核算需配套 Observer v0.5.4；这是 Observer 侧的独立修复。
