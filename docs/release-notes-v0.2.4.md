# CommandCode Provider v0.2.4

修复月度额度新增可选字段的异常解析，保留可信的余额、窗口和订阅状态。
保持 KISS：生产代码仅局部调整 quota，不修改 CPA 核心、Observer、UI、配置或依赖。

## 修复

- `monthlyCreditsGranted` 类型错误、溢出或负数只禁止月度进度，不再丢失合法余额和五小时/周窗口，也不以静态基准掩盖非法授额。
- `quantity` 类型错误不再抹掉套餐、账期或 `past_due`；非法席位只影响需要席位计算的团队基准，有效授额与个人套餐不受无关错误影响。
- 保留席位原有规则：缺失/null 或有限值小于 1 按单席处理；非法类型与溢出不冒充缺失。授额与席位各自局部解码，不引入通用解析层。
- 响应实际提供非空 `cancelAt` 或 `pendingPhase` 时，只省略月度重置日期；月度比例、来源、余额及五小时/周窗口保持不变。未返回这些状态字段时维持既有日期路径，不新增探测或轮询。
- 核心余额仍严格校验并 fail-fast；配额查询保持两个只读 GET、所选凭据作用域及既有超时。

## 升级与验证

- 保留现有配置和凭据，替换对应平台插件并重启 CPA 后刷新额度；无需重新导入凭据或删除数据库，本版不迁移 Observer 数据库。
- 配套 Observer 继续使用 v0.5.4，无需重复升级。
- 已确认反例、完整 Go 单测/vet/race、Node 62/62、发布资产测试及实际 CPA v8.0.23 隔离集成均通过。
- 候选原生库与正式 Observer 联调覆盖 CLI/Provider、三协议、流式/非流式、额度和重启幂等；缓存比例及动态成本保持正确。
- 所有验证使用合成凭据和回环 mock，未使用真实账号；公开 Web 字段不等于每个 `/alpha` 账号都会返回这些可选字段。
